# FlappyBird 🐦

Just a chill side project to unwind after work and have some fun.

A simple Flappy Bird clone in the browser – tap to flap, dodge the pipes, beat your high score.

## Built with
- TypeScript
- HTML5 Canvas

## How to run
git clone https://github.com/MagicStephen/FlappyBird.git
cd FlappyBird
npm install
npm run dev

## Controls
- **Space / Left click** – flap
